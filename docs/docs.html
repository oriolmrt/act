Getting Started

Introduction

Act is a minimalistic inline scripting language for HTML. It allows you to add interactivity to your web pages without writing JavaScript.

Installation

Add the script to your HTML:

<script src="https://cdn.jsdelivr.net/gh/oriolmrt/act@main/act.js"></script>

Quick Start

Add act@ attributes to your HTML elements:

<button act@click="#message << 'Hello!'">Click me</button>

And add a div to display the message:

<div id="message"></div>

Syntax

Selectors

Act uses CSS selectors to target elements. You can use any valid CSS selector to select elements on the page. The most common selectors are ID selectors (#id) and class selectors (.class).
